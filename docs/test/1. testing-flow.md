# 🧪 Hệ sinh thái Tích hợp Kiểm thử (Testing Flow & Architecture)

**Ngày cập nhật:** 21/03/2026  
**Chủ đề:** Tích hợp Unit Test & Integration Test cho nhánh Core MERN và WebRTC.

Tài liệu này ghi chép lại cách vận hành, khởi tạo và duy trì bộ Test cho hệ thống ChatHub để đảm bảo chất lượng Code (Code Quality) trước khi Push lên Git hoặc Deploy CI/CD.

---

## 1. Kiến trúc Kiểm thử (Testing Stack)

Dựa trên tính chất Real-time và quy mô dự án, chúng tôi chia bộ thử nghiệm làm 2 phân khu lớn:

### ⚙️ Backend (Node.js/Express)
- **Thư viện chính:** `jest`
- **Tích hợp API:** `supertest` (Gửi request độc lập không cần mở Port `5001`).
- **Database Ảo:** `mongodb-memory-server` (Chỉ tạo Database tạm thời lưu trên RAM khi chạy Test, tự gỡ bỏ khi Test xong để không làm bẩn DB chính).
- **ES Modules:** Do Backend sử dụng `"type": "module"`, Jest được chạy qua cờ `--experimental-vm-modules` để hỗ trợ Native JS Import/Export.

### 💻 Frontend (React/Vite)
- **Thư viện chính:** `vitest` (Module Test siêu tốc do Vite trực tiếp phát triển).
- **Môi trường ảo:** `jsdom` (Giả lập Trình duyệt DOM ngay trong Terminal Node.js).
- **Render UI:** `@testing-library/react` (Tương tác với UI như người dùng thật bằng cú click, gõ text).

---

## 2. Kịch bản Kiểm thử Hiện Tại (Test Cases)

### A. Nhóm Test Backend (`__tests__/auth.api.test.js` & `call.socket.test.js`)
*   **Đăng ký (Signup):** Kiểm tra mã băm Bcrypt có được tạo đúng không, có tự động trả về JWT Cookie qua HTTP-Only Header không.
*   **Đăng nhập (Login):** Bắn thử Request Login với sai Email/Password và trông chờ hệ thống báo lỗi `400` thay vì crash Server.
*   **Rate & Spam:** Giả lập gửi 6 lệnh `call:initiate` liên tục qua Socket.io-client, Server phải block lệnh số 6 bằng `rate_limited`.

### B. Nhóm Test Frontend (`__tests__/useCallStore.test.js`)
*   **Edge Case Cuộc Gọi (Người thứ 3):** 
    - Giả định Store đang ở trạng thái `callStatus = 'calling'`, 
    - Bắn thủ công hàm `handleCallRejected({ reason: 'busy' });`
    - Bộ test phải kiểm định (Assert) rằng toàn bộ Video Stream đã được huỷ bỏ, trạng thái đưa về `idle`, và `react-hot-toast` đã phát cảnh báo "Người này đang bận cuộc gọi khác".

## 3. Hướng dẫn sử dụng CLI

Để khởi chạy toàn bộ Hệ sinh thái Test Mẫu được thiết kế:

**Chạy Test Frontend:**
Ở thư mục `frontend/`, chạy lệnh:
```bash
npm run test
```
Vitest sẽ tự động quét các file có hậu tố `.test.js` trong thư mục `src/__tests__` để biên dịch.

**Chạy Test Backend:**
Ở thư mục `backend/`, chạy lệnh:
```bash
npm run test
```
Chương trình sẽ tự khởi động một MongoDB Cloud tạm gọi là Mock-Server, xử lý POST RESTFUL sau đó nhả kết quả Coverage xanh đỏ rõ ràng.
